# ML / AI Interview Prep

Skimmable, one-page notes for ML and AI engineering interviews. Every note is short enough to review in 5 minutes before a call.

## How to use this repo

1. **Before an interview:** skim the folder for that round (e.g. `ml-system-design/` for a design round) plus `company-notes/<company>.md`.
2. **Weekly:** re-read anything marked `Review` in the tracker below (spaced repetition).
3. **After an interview:** add the questions you were asked to the relevant note's *Quick Q&A* section.

## Structure

| Folder | What goes here |
| --- | --- |
| [`fundamentals/`](fundamentals/) | ML basics, statistics, probability, metrics, bias–variance |
| [`deep-learning/`](deep-learning/) | Architectures, optimization, transformers, attention |
| [`llms-and-agents/`](llms-and-agents/) | LLMs, agent harnesses, RAG, evals, fine-tuning |
| [`ml-system-design/`](ml-system-design/) | Worked design cases: recommendations, search, fraud, ranking |
| [`coding/`](coding/) | DSA patterns + ML algorithms implemented from scratch |
| [`notebooks/`](notebooks/) | Small runnable demos (e.g. a tiny ReAct agent) |
| [`behavioral/`](behavioral/) | STAR stories mapped to common questions |
| [`company-notes/`](company-notes/) | One page per company: role, team, products, questions asked |

## Note format

Every note follows [`TEMPLATE.md`](TEMPLATE.md): core idea → key concepts table → why it matters → quick Q&A → source. Keep notes to one page.
